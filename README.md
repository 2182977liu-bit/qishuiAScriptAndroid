# 汽水音乐 Android 自动化（汽水自动助手）

汽水音乐广告领取自动化的 Android 实现，提供**两种使用方式**：

- **方式一：AScript 脚本版** —— 安装 AScript 自动化引擎，导入本仓库的 `__init__.py` 运行。适合想改脚本、调参数、二次开发的用户。
- **方式二：独立 APK 版（汽水自动助手）** —— 直接安装编译好的 App，无需 AScript、无需电脑、无需写代码。适合只想开箱即用的用户。

功能流程参考 [wei6718189/qishuiAScriptProject](https://github.com/wei6718189/qishuiAScriptProject)（iOS 版），本仓库为独立重新实现的 Android 代码，不复制原项目图片资源，详见 [NOTICE](./NOTICE)。

> ⚠️ 本项目仅供个人学习研究。不绕过广告时长、次数限制、验证码或平台风控，不提供任何反检测能力。请遵守汽水音乐及广告服务的相关协议；出现“系统繁忙”或额度用完提示后不要反复运行。

## 功能

- 启动汽水音乐（Android 包名 `com.luna.music`）
- OCR 识别并跳过开屏广告、处理会员续费弹窗
- 用户手动进入第一个广告后，自动等待倒计时结束
- 支持普通视频广告、“继续观看”弹窗、直播互动提示与直播间退出
- 依次点击“领取成功”与“领取奖励”
- 检测当日额度提示，连续多轮无广告时自动停止
- 检测广告外跳并尝试切回汽水音乐

## 两种方案对比

| | 方式一：AScript 脚本版 | 方式二：独立 APK 版 |
| --- | --- | --- |
| 需要安装 | AScript + 汽水音乐 | 汽水自动助手 APK + 汽水音乐 |
| 需要电脑 | 不需要（可用电脑 WebIDE 调试） | 不需要 |
| 上手难度 | 中（需导入脚本、选运行模式） | 低（装好授权即可） |
| 可定制性 | 高（直接改 Python 常量与逻辑） | 低（需改 Kotlin 源码重新编译） |
| OCR 引擎 | PaddleOCR / ML Kit 可选 | ML Kit 中文（Offline 内置 / Lite 按需下载） |
| 适合人群 | 开发者、想调参的用户 | 普通用户 |

## 教程一：安装 AScript 运行脚本版（详细）

### 1. AScript 是什么

AScript 是一款 Android 上的 Python 自动化脚本引擎，免 Root，支持无障碍、图色、Root 等运行模式，内置 PaddleOCR、ML Kit 等识别能力。本脚本使用它的**无障碍模式**：控件查找 + OCR + 无障碍手势点击。

- 官网：<https://www.ascript.cn/>
- Android 下载页：<https://ascript.cn/docs/android/download/>

### 2. 下载安装 AScript

1. 手机浏览器打开上面的 Android 下载页（也可扫页面上的二维码）。
2. 2018 年以后的手机下载 **64 位版本**；老旧设备或模拟器才选 32 位版本。
3. 安装时系统提示“未知来源”，允许本次安装。
4. 本项目已在 AScript 4.0.17 上部署验证；建议直接使用最新版。

### 3. 配置 AScript 权限与模式

1. 打开 AScript，按引导开启**无障碍服务**（系统设置 → 无障碍 → 找到 AScript → 开启）。
2. 授予**屏幕录制/截屏**权限（OCR 识别需要）。
3. 授予**悬浮窗**权限（日志与控制面板）。
4. 国产手机建议把 AScript 加入电池优化白名单/允许后台运行，防止锁屏后被杀。
5. 运行模式选择**无障碍模式**。

> ⚠️ 不要使用 `screen_only` 或未配置点击实现的 HID 模式：这些模式不能直接使用本脚本的 `action.click`，需要自行接入点击通道。

### 4. 导入脚本

**方法 A：只在手机上操作（推荐）**

1. 下载本仓库代码：GitHub 仓库页 → `Code` → `Download ZIP`，解压得到 `__init__.py`。
2. 在 AScript 中新建一个 **Android 工程**，例如命名 `qishuiAScriptAndroid`。
3. 把 `__init__.py` 放到工程根目录，**文件名保持不变**。对应手机路径一般为：
   `/storage/emulated/0/airscript/model/<工程名>/__init__.py`
4. 若你的 AScript 版本支持工程导入（`.zip`），也可直接导入后确认入口文件为 `__init__.py`。

**方法 B：电脑 WebIDE（方便改代码）**

1. 手机和电脑连接同一个 WiFi。
2. AScript 首页点“**开发者**”，查看开发地址，形如 `http://192.168.0.101:9096`（以你手机实际显示为准）。
3. 电脑浏览器访问该地址，进入 WebIDE。
4. 新建 Android 工程，把本仓库 `__init__.py` 的完整内容粘贴进入口文件并保存。

> 脚本入口由 AScript 框架加载，文件末尾直接调用 `main()`，**不要**改成 `if __name__ == "__main__":`。

### 5. 运行

1. 确认手机已安装并登录汽水音乐（包名 `com.luna.music`）。
2. 在 AScript 中以无障碍模式运行工程。
3. 脚本自动启动汽水音乐、跳过开屏、处理会员弹窗。
4. 按日志提示**手动进入第一个广告**，之后的等待、领取、循环由脚本接管。
5. 额度用完或连续多轮无广告时脚本自动停止；也可在 AScript 中手动停止。

### 6. 可调配置（`__init__.py` 顶部常量）

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `APP_PACKAGE` | `com.luna.music` | 汽水音乐包名 |
| `OCR_ENGINE` | `paddle` | OCR 引擎，可改为 `mlkit` |
| `SELECTOR_MODE` | `2` | 无障碍控件模式；Root 通常改为 `9` |
| `MAX_ROUNDS` | `50` | 最大广告轮数 |
| `MAX_IDLE_ROUNDS` | `5` | 连续无广告退出阈值 |
| `FIRST_AD_TIMEOUT` | `120` | 首轮等待用户进入广告的秒数 |
| `AD_TIMEOUT` | `75` | 后续单轮基础等待秒数 |
| `MAX_AD_TIMEOUT` | `120` | 识别倒计时后允许延长到的上限 |
| `CLAIM_TIMEOUT` | `15` | 等待奖励弹窗的秒数 |

### 7. 实现要点

- 每轮优先做一次全屏 OCR，再在内存中匹配文字，减少重复截图。
- “领取成功”只匹配屏幕顶部，“领取奖励”只匹配中间弹窗区域。
- “继续观看”只匹配屏幕中间区域，并排除含“下载”“直播”“互动”的文本。
- 直播互动提示出现后只选择退出类按钮；进入直播间后依次尝试控件、OCR 和返回键。
- 所有 OCR 点击都必须命中有效文字和坐标，没有命中时不会盲点。

## 教程二：直接安装独立 APK（详细）

### 1. 设备要求

- Android 8.0 及以上（minSdk 26）
- **arm64 处理器**（2018 年以后的手机基本都满足；32 位老设备与 x86 模拟器不支持）
- 当前发行版为 **Debug 测试包、调试签名**，仅用于安装测试，不是商店正式签名包

### 2. 下载 APK

打开 [Releases 页面](https://github.com/2182977liu-bit/qishuiAScriptAndroid/releases)，下载最新版（当前 v0.2.1）：

| 版本 | 直链 | 大小 | 说明 |
| --- | --- | --- | --- |
| **Offline（推荐）** | [app-offline-debug.apk](https://github.com/2182977liu-bit/qishuiAScriptAndroid/releases/download/v0.2.1/app-offline-debug.apk) | 约 13.9 MB | 中文 OCR 模型内置，**不依赖 Google Play 服务**，国产手机直接可用 |
| Lite | [app-lite-debug.apk](https://github.com/2182977liu-bit/qishuiAScriptAndroid/releases/download/v0.2.1/app-lite-debug.apk) | 约 1.3 MB | 模型由 Google Play 服务按需下载，适合有完整 GMS 的设备 |

realme、华为、小米、OPPO、vivo 等无 GMS 或 GMS 不完整的手机，**一律选 Offline**。

### 3. 安装

1. 点击下载好的 APK，系统提示“未知来源”时允许安装。
2. 已装过旧版（0.1.0 / 0.2.0）可直接覆盖安装，无需卸载（同为调试签名，versionCode 已递增）。
3. 安装完成后桌面出现“**汽水自动助手**”。

### 4. 首次启动：按引导完成三项授权

打开 App，按界面提示依次完成：

1. **无障碍服务**：跳转系统设置 → 无障碍 → 已下载的应用/服务 → 找到“汽水自动助手”→ 开启。这是自动点击的基础。
2. **屏幕识别（录屏）**：回到 App 点授权，系统弹出“开始录制或投放”对话框时点“立即开始”。仅用于本机 OCR 识别，不上传。
3. **悬浮窗**：跳转系统设置允许显示在其他应用上层。用于显示控制窗和日志。

三项都就绪后，App 显示可开始状态。

### 5. 开始自动化

1. 点“开始”。App 自动启动汽水音乐、跳过开屏广告、处理会员弹窗。
2. 按提示**手动进入第一个广告**（例如“看广告领会员/听歌时长”入口）。
3. 之后全自动：等待倒计时 → 处理“继续观看”/直播跳转 → 点击“领取成功”→ 点击“领取奖励”→ 下一轮。
4. 额度用完或连续多轮无广告时自动结束。

### 6. 悬浮控制窗操作

- **拖动**：按住标题栏“⋮⋮ 汽水助手”拖动，位置限制在屏幕内。
- **最大化**：显示运行状态、已领取次数和实时日志；日志在底部时自动滚动，向上翻看时不会强制拉回。
- **最小化**：恢复为小窗，保留之前的小窗位置。
- **停止**：小窗和大窗都有“停止”按钮；也可下拉通知栏点“停止”。
- **领取阶段悬浮窗会临时消失**：这是 v0.2.1 的预期行为，避免悬浮窗遮挡或拦截“领取奖励”按钮，领取完成后自动恢复为小窗。隐藏期间仍可用通知栏停止。

### 7. 日志关键词速查

| 日志 | 含义 |
| --- | --- |
| `通过控件点击领取奖励` | 走无障碍控件点击成功（优先路径） |
| `点击 领取奖励 (x,y)` | 走 OCR 坐标点击（兜底路径） |
| `未找到可点击的领取奖励按钮，本轮失败` | 15 秒内没找到可点击按钮，检查弹窗样式 |
| `检测到当日额度已用完` | 平台额度限制，自动停止，不要反复运行 |
| `检测到离开汽水音乐（…），尝试拉回` | 广告外跳，自动切回 |
| `OCR 识别异常` / `屏幕缓冲区不足` | 识别层问题，重启 App 重试；持续出现请反馈日志 |
| `系统停止了屏幕采集` | 录屏授权被系统回收，重新授权 |

### 8. 停止与卸载

- 临时停止：悬浮窗或通知栏“停止”。
- 彻底关闭自动化：系统设置中关闭“汽水自动助手”的无障碍服务。
- 卸载：正常卸载 App 即可，不影响汽水音乐。

## 常见问题与风险说明（两种方式通用）

**Q：提示“系统繁忙”、广告自动退出？**
这通常是平台风控、账号/设备状态或广告服务异常，不一定是脚本问题。先停止自动化，手动观看一次广告对照：手动也异常请联系汽水音乐官方客服；只有自动化运行时异常，再检查日志中的点击与外跳记录。**本项目不提供反检测或风控绕过。**

**Q：点不到按钮 / 识别不准？**
广告页面是动态内容，OCR 受字体、清晰度、分辨率和 App 版本影响。脚本版可调整识别区域常量；APK 版请反馈日志与机型。

**Q：锁屏/切后台后停止？**
国产系统会杀后台。把 AScript 或汽水自动助手加入电池优化白名单、允许自启动与后台运行，运行期间尽量保持亮屏。

**Q：会不会封号？**
任何自动化领取都可能违反平台协议并触发限制，风险自负。出现额度用完或“系统繁忙”后立即停止，不要反复重试。
